# 이베이 대표이미지 제작

자동차 부품 사진의 배치 규칙, 작업 도구와 로컬 이미지 편집 앱을 보관하는 저장소입니다.

- [사진 작업 규칙](작업규칙.md): 이미지 규격, 균형, 라벨, 워터마크, 파일명.
- [에이전트 지침](AGENTS.md): 작업 시작 시 확인할 최신 사용자 설정.
- [작업 방식 및 명령](docs/WORKFLOW.md): 처리 순서, 도구 사용법, 검수 기준.
- [새 컴퓨터 이전 안내](docs/MIGRATION.md): 설치 및 별도 이전 항목.
- [앱 실행 안내](korea-autoparts-studio/README.md).

2026-09-05 현재 음성 보고와 추가 유료 API 호출은 중단 상태입니다. 설치 확인에는 API를 호출하지 않습니다.

GitHub에는 규칙, 문서와 작업 명령 도구를 보관합니다. 앱 소스와 승인 기준 이미지는 공개 업로드 승인 대기 상태이며, 기존 컴퓨터의 전체 소스 백업 ZIP에 보관합니다. API 키, 원본/완성 사진 전체, 음성 파일, Codex 대화 이력은 포함하지 않습니다. 문서는 대화에서 확정된 작업 지침의 정리이며 대화 전문 백업이 아닙니다.
