# eBay 상품 등록 실행 규칙

이 문서는 등록 묶음의 작업 순서와 출고 검수표다. 상세 기준은 [`LISTING_RULES.md`](LISTING_RULES.md), 계정 분리는 [`EBAY_ACCOUNTS.md`](EBAY_ACCOUNTS.md), 사진은 [`PHOTO_WORK_RULES.md`](PHOTO_WORK_RULES.md)와 저장소 루트의 [`작업규칙.md`](../작업규칙.md)를 따른다. 날짜·품번·정책 ID가 적힌 지난 등록 기록은 새 상품에 그대로 복사하지 않는다.

## 시작 전 입력과 계정

1. 날짜별 작업표에서 **참고 아이템 번호, USD 가격, 배송 정책, 품번, 상품별·전체 메모, 에이전트 배정**을 확인한다. 비어 있는 필수 값은 추측하지 않는다. 메모의 추가 지시를 반영한다.
2. 반드시 미국 `gandakorea` / `EBAY_US` / USD 계정에 **먼저 연결**하고 API 인증 판매자 또는 실제 로그인 판매자 ID를 확인한다. 해당 묶음의 **미국 전체 등록과 검수**를 끝낸 뒤 호주 `sihooshop` / `EBAY_AU` / AUD로 전환한다. 호주에서도 변경 직전 판매자 ID를 다시 확인한다. 사이트 도메인이나 탭만으로 계정을 판정하지 않는다.
3. 두 판매자의 인증 정보, 정책 ID, 가격·통화, 호환표, 등록 번호를 따로 보관한다. 미국 자격 증명에 호주 값을 대입하거나 한쪽 정책을 다른 계정에 복사하지 않는다.

## 출고지 고정 — 2026-10-10 사용자 확정

- 사용자 지시 “앞으로 출고지는 무조건 서울이야 규칙으로 체크해놔.”에 따라 미국·호주를 포함한 모든 신규 상품의 출고지는 서울, 대한민국으로 고정한다. 도시 `Seoul`, 국가 `KR`이며 같은 지역을 표시하는 `Seoul, South Korea`도 허용한다.
- 준비 패키지·서버 전송·등록 후 API/공개 검수에서 서울을 체크한다. 참고 상품·옛 템플릿의 용인 등 다른 도시를 출고지로 복사하지 않으며 출고지와 제조 원산지는 구분한다. 서울/용인 선택을 반복 질문하지 않는다.
- 현재 2026-10-10 호주 8상품의 실제 `Seoul`은 사용자 확정값으로 승인한다. 기존 기대 용인 및 immutable manifest는 보존하고 별도 지시 근거를 연결해 최종 검수·완료 기록을 진행한다. 이전 다른 등록 상품은 일괄 변경하지 않는다.

## 상품별 준비

- 참고 아이템을 조회해 실제 품번, 판매 내용, eBay **아이템 카테고리**와 미국 차량 호환표를 확인한다. 제목에 등장하는 각 차종에 맞춰 현재 계정의 **스토어 카테고리**를 별도로 고른다.
- 제목은 `⭐Genuine 품번 부품명 For 차종 배기량 연식` 형식으로 **80자 이내**로 만든다. 별은 유지하고, 품번은 하이픈 없이 쓴다. 2개 묶음은 부품명 뒤 `2EA`, 좌우 한 쌍은 `Left Right 2EA`를 쓴다. 길면 먼저 제목의 품번을 빼고, 그래도 초과하면 양끝 연도를 두 자리로 줄인다. 허용된 좌우 축약은 `LH RH 2EA`다. 세부 판단은 `LISTING_RULES.md`를 따른다.
- 상품 상태는 `New`, 판매 재고는 **5개**, Brand는 `Genuine Hyundai Mobis`로 둔다. Country of Origin은 `Korea, Republic of`를 원칙으로 하되 실제 라벨의 명시적 생산국과 충돌하면 확인 전 임의 입력하지 않는다. California Prop 65 Warning은 복사하거나 입력하지 않는다.
- 매번 아이템 `336779935333`의 현재 판매자 설명 전체를 조회해 서식·표·VIN 그림을 유지한다. 템플릿의 옛 상품 제목·품명·품번·차종 문구는 현재 상품 정보로 고친다. 설명 안에 **현재 제목이 문자 그대로** 들어가야 하며 공개 후 그림 로딩도 확인한다.
- 등록 사진은 해당 품번의 검수 완료된 로컬 `완성본/<파츠넘버>/` PNG만 사용한다. 대표사진 `파츠넘버.png` 다음 `_1.png`, `_2.png` 순서다. 참고 판매자의 URL, 수정 전 사진, 다른 품번 사진을 사용하지 않는다. 사진 개수, 해시와 순서를 업로드 전후 확인한다.
- 미국은 사용자가 지정한 USD 가격을 사용한다. 호주는 등록 시점에 확인한 USD/AUD 환율로 AUD 가격을 계산해 센트 단위로 반올림한다. `normal`/`fast`라는 입력은 각 판매자의 **실제 현재 정책**에 대응시켜 ID·이름을 확인한다. 정책 이름만 같다고 계정 간 ID를 재사용하지 않는다.
- 미국 호환표는 참고 상품의 API 실제 행을 가져와 적용하고 저장 후 전체 값과 개수를 검증한다. 호주는 미국 행을 복사하지 않는다. OEM 적용 근거와 eBay Australia 카탈로그의 `Make`, `Model`, `Year`, `Submodel`, `Variant`, `Engine` 값을 대조해 **실재하고 확실한 조합만** 적용한다. 불확실한 조합은 추가하지 않고 VIN 또는 OEM 자료로 확인한다.


## 호주 글로벌 판매·등록 진행 — 2026-10-07 사용자 확정

- 호주 eBay 등록은 호주 구매자만을 위한 판매가 아니라 전 세계 구매자 대상이다. 사용자가 등록을 지시하면 호주 현지 차종·RHD 적용 근거가 미확정이라는 이유만으로 미등록·보류로 판단하거나 진행 승인을 반복 요청하지 않고 등록을 진행한다.
- 참고 상품과 실물로 확인된 품번·제품 정보·판매 범위를 유지하며, AU 시장만을 대상으로 차종·엔진·제목을 임의 축소하거나 변환하지 않는다. Forte 등 원래 판매 차종을 Cerato로 추측 변경하지 않는다.
- 확인되지 않은 호환 조합은 만들어 넣지 않는다. AU 카탈로그와 장착 근거로 확인된 행만 적용하며, 확인된 행이 없으면 호환표를 비워 등록한다. 호환표가 비어 있다는 사실 자체는 등록 차단 사유가 아니다.
- 이 규칙은 기존 문서의 AU 장착 미확정·빈 호환표에 따른 보류 기준보다 우선한다. 실제 계정, 품번, 가격·환율, 정책, 사진, 등록 결과 검수와 서비스·도구 자체의 인증·승인 제한은 유지한다.

## 등록과 완료 판정

1. 공개 등록 직전 계정·마켓, 품번, 제목, 상태, 가격·통화, 수량 5, 카테고리, 배송·반품·결제 정책, 본문, 사진, 호환표를 확인한다. 2026-10-06 사용자 규칙: 중복 등록 여부는 조사하거나 차단 조건으로 삼지 않는다. 기존 동일 품번·SKU·상품이 있더라도 요청 상품은 요청대로 신규 등록하고, 중복 때문에 대기하거나 추가 승인을 요청하지 않는다.
2. 미국 묶음 전체를 등록하고 공개 상품 및 API로 판매자 `gandakorea`, Active 상태, USD 가격, 사진 URL·수량·순서, 본문 제목·VIN 그림, 호환표 **전체 값**을 검수한다. 이 검수가 끝난 뒤에만 호주를 시작한다.
3. 호주 묶음에도 같은 검수를 `sihooshop`, `EBAY_AU`, AUD와 별도 호환표 기준으로 시행한다. 공개 화면에서 대표사진과 갤러리 전체, 수량과 그림의 실제 로딩을 확인한다.
4. 성공한 각 상품의 **계정·마켓·품번·상품 번호·링크·가격·사진 장수·호환 행수**를 결과와 날짜별 작업표에 기록한다. 기존 다른 에이전트 행은 보존한다. 오류나 불확실성이 있으면 해당 상품을 완료로 표시하지 않는다.
5. 자동 예약 작업을 쓴다면 검수 완료 사진과 패키지의 품번 연결을 확인한다. 비공개 보관용 전송과 즉시 등록을 유발하는 API를 혼동하지 않는다. 통신 오류로 같은 실행의 결과가 불명확하면 정확한 대상의 실제 결과를 확인한다. 기존 상품의 중복 여부는 신규 요청의 등록 차단 조건으로 삼지 않는다. 토큰·비밀 키는 Git이나 작업표에 저장하지 않는다.
