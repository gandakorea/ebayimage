# eBay 사진 작업 실행 규칙

이 문서는 새 품번이나 새 묶음을 시작할 때 확인할 실행 순서다. **시각적 판단의 원본 기준은 저장소 루트의 [`작업규칙.md`](../작업규칙.md)**이며, 파일이 충돌하면 그 문서를 우선한다. 사용자 제공 사진에 `1000픽셀 사이즈로 가운데 워터마크만 넣어줘`라는 별도 지시가 있으면 [`USER_SUPPLIED_IMAGE_WATERMARK_RULES.md`](USER_SUPPLIED_IMAGE_WATERMARK_RULES.md)를 적용한다.

## 작업 전

1. 매 새 품번·묶음마다 `AGENTS.md`, `작업규칙.md`, `docs/WORKFLOW.md`를 다시 읽고 사용자에게 편집 방향을 먼저 알린다. 규칙 확인 전에는 편집하거나 eBay에 사진을 업로드하지 않는다.
2. 참고 eBay 아이템의 사진을 모두 수집하여 **원본 그대로 보관**한다. 원본 사진의 글은 제품 자료로 취급한다.
3. 사진마다 `라벨+제품`, `라벨+제품 박스+제품`, `제품+제품 박스`, `제품만`, `복수 라벨+복수 제품` 중 유형을 확인한다. 제품·박스·라벨이 보이는 모든 사진을 가능한 최대 수량으로 작업한다. 제품이 없는 장착 예시·도해·배너는 원본만 보관한다.
4. 원본의 품번 라벨과 참고 상품 정보가 일치하는지 확인한다. 읽을 수 없거나 다른 품번이면 추측해서 파일명이나 라벨을 만들지 않는다.

## 한 장씩 편집

- 매번 **새 원본 한 장**에서 시작한다. 이전 완성 사진을 다음 각도 사진의 원본으로 삼지 않는다. 제품의 형태, 색상, 각인, 단자, 구멍, 질감, 박스 부착 라벨과 홀로그램을 원본과 대조해 보존한다. 생성 결과가 이 정보를 바꾸면 원본 픽셀로 복원하거나 재작업한다. 보이지 않는 구조를 만들어 사실로 취급하지 않는다.
- 최종 파일은 **1000 × 1000 px PNG, 흰 배경**이다. 제품·라벨·박스 밖의 그림자, 회색 배경, 얼룩과 기존 사진의 워터마크를 정리한다. 어떤 부분도 잘리지 않게 하고 시각적 균형을 우선한다.
- **첫 장:** 분리된 품번 라벨과 은색 홀로그램을 원본 픽셀로 한 세트로 보존하여 상단 중앙에 둔다. 흰색 라벨 본체 폭은 약 350 px, 홀로그램과의 상대 비율·위치는 유지한다. 세트 위에 약 20 px 흰 여백을 두고, 제품은 라벨 아래 **남은 공간의 가로·세로 중앙**에 최대한 크게 배치한다.
- **두 번째 장부터:** 사진과 별도로 놓인 품번 라벨과 홀로그램을 모두 제거하고 제품만 남긴다. 제품이나 박스에 실제로 붙은 라벨은 어느 장에서도 제거하지 않는다.
- **별도 라벨+제품 박스+제품** 유형은 예외다. 첫 장이어도 별도 라벨을 제거하고 제품과 박스를 하나의 세트로 중앙에 둔다. 박스에 붙은 실제 라벨은 보존한다. 복수 라벨·복수 제품은 `작업규칙.md`의 전용 배치 규칙을 따른다.
- 모든 완성 장에 `KOREA AUTOPARTS`를 적용한다. `assets/fonts/NotoSans-BoldItalic.ttf`를 사용하고 전체 폭은 약 **264 px**로 고정한다. 흰색 계열 반투명 글자와 얕은 짙은 외곽선 또는 음영을 유지한다. 라벨형은 제품 중앙, 일반 제품·박스형은 해당 세트 중앙에 놓으며 사진마다 크기를 바꾸지 않는다.
- 다른 원본 사진의 실제 픽셀을 같은 품번의 라벨·각인 복원에 사용했다면 어떤 사진에서 가져왔는지 사용자에게 밝힌다. 라벨의 글씨, 바코드, 로고, 작은 한글을 생성해서 다시 쓰지 않는다.

## 저장과 출고 차단 검사

1. 원본은 보존하고 최종 파일을 `완성본/<파츠넘버>/`에 `파츠넘버.png`, `파츠넘버_1.png`, `파츠넘버_2.png` 순서로 저장한다. 품번의 공백은 하이픈, 영문은 대문자로 쓴다.
2. 완성할 때마다 해당 **1000 × 1000 파일을 한 장씩 열어 사용자에게 보여준다.** 원본과 나란히 보며 제품·박스 잘림, 각인·라벨·홀로그램 변형, 첫 장 상단 중앙 라벨과 제품 중앙 배치, 후속 장 별도 라벨 제거, 흰 배경과 고정 워터마크를 확인한다. 축소 연락처 시트나 자동 크기 검사만으로 통과시키지 않는다.
3. 최종 파일 수와 순서가 제품 사진 수와 맞는지 검사한다. 위 검사를 통과하지 못한 파일은 등록 패키지나 eBay에 올리지 않는다. 등록 후에도 공개 상품의 사진 수·순서·실제 로딩을 확인한다.
