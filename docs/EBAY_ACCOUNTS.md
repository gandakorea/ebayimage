# 미국·호주 eBay 계정 분리

2026-09-08 사용자 지시: 미국 계정과 호주 계정을 구분하여 작업한다.

## 최우선 작업 규칙

1. 미국 `gandakorea`와 호주 `sihooshop`은 서로 완전히 분리한다.
2. 사용자가 상품 작업을 지시하면 **무조건 미국 계정 `gandakorea`에 먼저 접속한다.**
3. 미국 계정에서 해당 작업 묶음의 등록과 검수를 모두 완료한 뒤에만 호주 계정 `sihooshop`으로 전환한다.
4. 호주 작업을 먼저 시작하거나, 미국과 호주 작업을 섞어서 진행하지 않는다.
5. 각 계정에 접속한 직후와 등록 직전에 실제 판매자 ID를 확인한다.

| 작업 대상 | 판매 계정 | 등록 통화 | 마켓플레이스 |
|---|---|---|---|
| 미국 | gandakorea | USD | EBAY_US |
| 호주 | sihooshop | AUD | EBAY_AU |

## 매 작업 전 확인

1. 판매자 허브에 표시된 실제 판매자 ID를 확인한다. ebay.com과 ebay.com.au 주소만으로 계정을 판단하지 않는다. ebay.com에서도 sihooshop으로 로그인될 수 있다.
2. API를 쓰면 인증된 판매자 ID와 대상 마켓플레이스를 각각 확인한다. 개발자 앱 이름이나 환경 변수 이름만으로 판매 계정을 추정하지 않는다.
3. 계정이 일치한 뒤에만 초안 작성, 사진 업로드, 상품 수정 또는 등록을 실행한다. 다른 계정이면 변경 작업을 중단한다.
4. 계정 전환 후, 그리고 최종 등록 직전에 판매자 ID를 다시 확인한다. 같은 브라우저의 탭들이 로그인 상태를 공유할 수 있으므로 탭 분리만으로 계정이 분리되었다고 판단하지 않는다.

## 자료와 인증 분리

- 미국과 호주의 액세스 토큰·갱신 토큰은 별도로 취급한다. 한쪽 인증을 다른 쪽 인증 값에 덮어쓰거나 대체하지 않는다.
- 가격·통화·배송 정책 ID·스토어 카테고리·호환표·초안 ID·등록 ID는 국가와 판매자 ID를 함께 기록한다.
- 상품 정보와 사진을 재사용하더라도 각 계정의 정책과 호환표는 별도로 확인한다.
- 인증 만료 시 해당 계정의 저장된 갱신 정보와 기존 작업 경로를 먼저 확인한다. 개발자 로그인과 판매자 로그인을 혼동하거나 불필요하게 재로그인을 요구하지 않는다.
- 비밀 키와 토큰 값은 이 문서나 Git에 저장하지 않는다.

## 작업 순서

- 모든 상품 작업은 미국 `gandakorea`에 먼저 접속하여 작업과 검수를 완료한 뒤, 호주 `sihooshop` 작업을 진행한다.
- 호주는 AUD 가격과 호주 차량 카탈로그에 맞는 호환표를 적용한다.
- 완료 보고에는 국가·판매 계정·등록 번호를 함께 표시한다.
