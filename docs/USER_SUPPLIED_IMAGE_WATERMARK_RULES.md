# 사용자 제공 사진 단순 워터마크 작업 규칙

## 적용 조건

- 사용자가 사진을 직접 제공하면서 **`1000픽셀 사이즈로 가운데 워터마크만 넣어줘`**라고 지시한 경우에만 적용한다.
- 이 규칙은 일반적인 이베이 사진 수집·배경 정리·기존 워터마크 제거 작업과 구분한다.

## 작업 원칙

1. 원본 사진의 제품, 박스, 라벨, 글자, 색상, 밝기, 선명도 및 배경을 수정하지 않는다.
2. 원본 비율을 유지한다. 사진을 늘이거나 눌러서 제품 형태를 변형하지 않는다.
3. 사진 전체가 잘리지 않도록 1000×1000픽셀 흰색 캔버스 안에 맞춘다.
4. 남는 공간은 흰색으로 채운다.
5. 기존 프로젝트의 승인된 `KOREA AUTOPARTS` 워터마크만 사용한다.
6. 워터마크는 1000×1000 캔버스의 정중앙에 한 번만 배치한다.
7. 추가 문구, 로고, 테두리, 배지, 효과 또는 다른 워터마크를 넣지 않는다.
8. 작업 전에 원본 파일 수를 확인하고 모든 사진을 빠짐없이 처리한다.
9. 완성 파일은 파츠넘버 폴더에 저장한다.
10. 첫 사진은 `파츠넘버.png`, 이후 사진은 `파츠넘버_1.png`, `파츠넘버_2.png` 순서로 저장한다.
11. 저장 후 모든 파일이 정확히 1000×1000픽셀인지 확인한다.
12. 저장 후 각 사진의 비율, 잘림 여부, 워터마크 위치 및 원본 훼손 여부를 눈으로 확인한다.
13. 사용자의 확인 전에는 이베이 등록 사진을 교체하거나 업로드하지 않는다.

## 금지 사항

- 배경 제거 또는 배경색 보정
- 기존 요소 삭제
- 라벨 재작성 또는 글자 선명화
- 제품 재구성 또는 다른 사진으로 대체
- 색상·노출·대비·채도·선명도 변경
- 자동 크롭으로 제품이나 박스를 자르는 작업
- 사용자가 요청하지 않은 추가 편집
