# 2026-10-04 eBay 상품등록 작업 규칙

이 문서는 상품등록을 **준비 → 미국 전체 등록·검수 → 호주 전체 등록·검수 → 결과 보고** 순서로 처리하기 위한 실행 기준이다. 계정 분리는 [`EBAY_ACCOUNTS.md`](EBAY_ACCOUNTS.md), 상품 필드의 상세값은 [`LISTING_RULES.md`](LISTING_RULES.md), 사진은 [`PHOTO_WORKFLOW_2026-10-04.md`](PHOTO_WORKFLOW_2026-10-04.md)와 [`작업규칙.md`](../작업규칙.md)를 따른다. 최신 사용자 지시와 날짜별 작업표의 상품별·전체 메모를 확인하고, 과거 작업 기록의 가격·정책 ID·상품 번호를 새 상품에 그대로 복사하지 않는다.

## 1. 작업표와 자료 확인

1. 지정된 **한국 날짜**의 작업표에서 에이전트 배정, 참고 eBay 아이템 번호, 품번, 사용자 지정 USD 가격, `normal`/`fast` 배송 구분, 상품별 메모와 전체 메모를 읽는다. 필수 값이 실제로 비어 있고 저장된 자료로도 확인할 수 없을 때만 묻는다.
2. 참고 아이템의 실제 상품 내용과 **eBay 아이템 카테고리**, OEM 품번, 적용 차종·연식을 확인한다. 스토어 카테고리는 제목에 포함된 차종과 해당 판매 계정 기준으로 별도 선택한다.
3. 해당 품번의 검수 완료된 `완성본/<품번>/` 사진을 확인한다. 대표사진 `<품번>.png`부터 `_1.png` 순서로 모든 최종 PNG를 사용한다. 참고 판매자의 사진 URL, 다른 품번 사진, 수정 전 사진으로 대체하지 않는다. 홀로그램 유무는 등록 판단에서 무시한다.
4. 기존 SKU·초안·활성 상품을 조회해 의도하지 않은 중복을 확인한다. **중복을 허용하거나 같은 품번에서 하나만 등록하라는 사용자 지시가 해당 작업 묶음에 있으면 그 지시를 적용**하고, 적용 범위를 기록한다.

## 2. 계정 순서와 분리

1. 항상 미국 판매자 **`gandakorea` / `EBAY_US` / USD**에 먼저 연결한다. 접속 직후와 작성·수정·공개 등록 직전에 실제 로그인 또는 API 인증 판매자 ID를 확인한다. 도메인, 브라우저 탭, 앱 이름만으로 판매자를 추정하지 않는다.
2. 요청된 묶음의 **미국 상품 전체 등록과 공개 결과 검수**가 끝난 뒤에만 호주 판매자 **`sihooshop` / `EBAY_AU` / AUD**로 전환한다. 미국·호주 작업을 상품별로 번갈아 처리하지 않는다.
3. 판매자별 인증 정보, 통화, 가격, 배송·반품·결제 정책 ID, 스토어 카테고리, 차량 호환표, SKU·초안·등록 번호를 분리한다. 호주 인증이나 정책 ID를 미국 작업에 대입하지 않는다. 토큰·비밀값은 Git, 작업표, 결과 보고에 남기지 않는다.

## 3. 상품별 입력 기준

- **제목:** `⭐Genuine 품번 부품명 For 차종 배기량 연식` 형식을 80자 이내로 적용한다. 품번은 하이픈 없이, `2EA`와 `Left Right 2EA`는 실제 묶음 구성에 맞게 쓴다. 길이 초과 시 품번 제거, 이후 양끝 연도 두 자리 축약 등 [`LISTING_RULES.md`](LISTING_RULES.md)의 순서를 따른다.
- **기본값:** Item condition `New`, Brand `Genuine Hyundai Mobis`, 판매 재고 Quantity `5`. Country of Origin은 `Korea, Republic of`를 원칙으로 하되 실제 원본 라벨의 명시적 생산국과 충돌하면 임의로 한국으로 쓰지 않고 확인한다. California Prop 65 Warning은 비운다.
- **설명:** 매번 참고 아이템 `336779935333`의 판매자 설명을 조회한다. 서식·표·그림·VIN 안내를 유지하면서 예전 상품 제목·품번·차종을 현재 상품 정보로 바꾼다. 설명 안에 현재 제목이 문자 그대로 들어가는지 확인한다.
- **가격·배송:** 미국은 작업표의 USD 가격을 적용한다. `normal`은 `7day normal`, `fast`는 `7day fast`에 대응시키되 해당 판매자의 실제 현재 정책 ID를 확인한다. 호주는 사용자 지시가 따로 없으면 등록 시점에 확인한 환율로 AUD 가격을 계산해 센트 단위로 반올림하고, 호주 계정 정책을 별도로 적용한다.
- **차량 호환표:** 미국은 참고 아이템의 실제 API 호환 행을 확인해 일괄 적용하고 저장 후 값과 개수를 재조회한다. 호주는 미국 표를 복사하지 않는다. OEM 적용 근거와 eBay Australia 카탈로그의 Make·Model·Year·Submodel·Variant·Engine을 대조해 확인된 조합만 적용한다. 불확실한 장착 정보는 추정하지 않는다.
- **Item specifics:** 품번, 부품명, 위치, 수량·좌우 구성 등 확인 가능한 값을 사진·참고 아이템·OEM 자료와 맞춘다. 특정 품번이나 변형 품번을 함께 넣으라는 상품별 메모가 있으면 그 범위만 반영한다.

## 4. 공개 전·후 검수

1. 각 등록 직전에 **실제 판매자·마켓**, 품번·SKU, 제목, 아이템/스토어 카테고리, 상태, 가격·통화, Quantity, 정책, Item specifics, 설명, 사진 순서·장수, 호환표를 확인한다. 필요한 검수가 끝난 상품은 이미 받은 등록 승인 범위 안에서 끝까지 진행한다.
2. 공개 후 API와 실제 상품 화면에서 Active 상태, 판매자 ID, 가격·통화, 제목, 사진 URL·장수·순서와 로딩, 설명의 현재 제목·그림, 호환표 전체 값·개수를 다시 확인한다. 초안 저장이나 API 성공 응답만으로 공개 완료라고 보고하지 않는다.
3. 미국 묶음 검수가 끝난 다음 호주에 같은 검수를 반복한다. 호주의 판매자, AUD 가격, 정책, 카탈로그 호환표는 독립적으로 확인한다.
4. 결과에는 **국가·판매 계정·품번·상품 번호·공개 링크·가격·사진 장수·호환 행수**와 오류·미완료 사유를 기록한다. 날짜별 작업표의 다른 에이전트 행은 보존한다. 검증되지 않은 상품은 완료로 표시하지 않는다.
