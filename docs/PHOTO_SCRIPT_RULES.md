# 사진 처리 스크립트 사용 규칙

## 현재 사진 보관·업로드 방식 — 2026-10-13

- 사진 원본과 완성본은 로컬 컴퓨터에 보관한다. 완성본은 `완성본/<품번>/`에 품번 순서로 저장하고, 기존 파일을 교체할 때 먼저 백업한다.
- Vercel Blob과 Cloudflare D1/KV/R2/Assets에 사진·썸네일·이미지 base64를 저장하지 않는다. 등록 사진의 업로드 목적지는 eBay EPS이다.
- Cloudflare에는 작업표와 문자 메타데이터·해시·EPS URL·등록 결과만 저장한다. 로컬 업로드·검수 방법은 [Cloudflare 운영 안내](CLOUDFLARE_OPERATION.md)를 따른다.
- 생성형 편집으로 라벨·품번·바코드·각인·제품 형상이 바뀐 사진은 채택하지 않는다. 원본 픽셀 보존·복원 후 완성 파일 전 장을 개별 대조하고, 실제 공개 갤러리의 장수·순서·로딩을 검수한다.

작성일: 2026-10-05, 한국 시간

이 문서는 이베이 제품 사진을 처리할 때 사용하는 Python 스크립트의 역할, 작업 순서와 검수 기준을 설명한다. 별도의 맥 앱이나 버튼 하나로 모든 사진을 처리하는 완성 자동화 도구는 아니다. 사진의 최종 시각 규격은 [작업규칙.md](../작업규칙.md)를 기준으로 하며, 최신 사용자 지시가 우선한다.

## 도구의 역할

### 공통 마무리 도구

대상 파일: `tools/finalize_product_images.py`

이미 배경과 기존 판매자 워터마크 정리가 끝난 사진을 최종 규격으로 마무리한다. 1000×1000 캔버스, 밝은 배경 정리, 원본 라벨 배치, 고정 스타일의 KOREA AUTOPARTS 워터마크, 품번별 PNG 저장에 사용한다.

이 도구는 제품을 자동으로 정확히 추출하거나 기존 판매자 워터마크를 모두 제거하는 도구가 아니다. 배경 정리와 원본 대조는 별도로 수행한다.

### 10월 4일 원본 표기 복원 스크립트

대상 파일: `tools/restore_photo_pixels_20261004.py`

25110-2G500과 81320-F2040 사진에 맞춰 작성한 작업 기록용 스크립트다. 원본 사진과 이미지 편집 결과를 맞춘 뒤 실제 원본 라벨·중요 표기 영역을 편집 결과에 복원하고, 배치와 워터마크를 적용한다.

품번, 날짜, 생성 이미지 식별자, 라벨 위치, 워터마크 위치와 복원 영역이 해당 사진에 맞게 고정되어 있다. 새 품번에 그대로 실행하지 않는다. 실행에 필요한 편집 이미지가 없으면 재사용할 수 없으며, 입력 경로와 좌표부터 수정해야 한다.

## 실행 전에 준비할 자료

- 변경하지 않은 원본 사진 전체와 사진별 품번·각도·순서.
- 각 원본에 대응하는 배경 및 판매자 워터마크 편집 결과.
- 원본 라벨과 보존할 각인·제조 표기·바코드의 위치.
- 첫 장, 후속 장, 제품과 박스가 함께 있는 장, 단자 확대 장의 구분.
- `assets/fonts/NotoSans-BoldItalic.ttf` 글꼴 파일.
- Python 실행 환경과 필요한 라이브러리. 공통 마무리 도구는 Pillow를 사용하고, 원본 표기 복원 스크립트는 OpenCV·NumPy·Pillow를 사용한다.

입력 자료와 실행 환경을 확인하기 전에는 기존 완성본을 덮어쓰지 않는다. 사진 편집 도구/API 사용은 사용자의 상시 승인 범위에서 진행하며, 음성 및 사진 외 추가 유료 API 금지는 유지한다.

## 작업 순서

1. 작업규칙.md와 해당 배치의 메모를 먼저 읽고 편집 내용을 사용자에게 알린다.
2. 원본을 보존하고 작업 사본을 만든다. 원본별 편집 결과의 대응 관계를 기록한다.
3. 사진을 분류한다. 첫 장의 별도 라벨, 후속 장에서 제거할 별도 라벨, 제품·박스에 실제 붙은 라벨을 구분한다.
4. 기존 판매자 워터마크와 불필요한 배경을 제거한다. 제품 위 워터마크를 제거한 부분은 원본과 확대 비교한다.
5. 원본과 편집 결과의 위치를 맞춘다. 자동 정렬 결과도 형상·각도·가장자리로 확인한다.
6. 실제 원본 라벨과 중요한 표기를 복원한다. 생성 모델이 그린 글자·품번·바코드를 원본 정보로 사용하지 않는다.
7. 제품과 필요한 라벨·박스를 흰 캔버스에 배치한다. 제품 전체를 보존하면서 사용 가능한 공간의 중앙을 맞춘다.
8. 고정 규격의 KOREA AUTOPARTS 워터마크를 넣는다. 품번·단자·중요 각인을 가리면 크기를 바꾸지 말고 위치를 조정한다.
9. 검수용 폴더에 품번 순서대로 저장하고 한 장씩 검수한다.
10. 합격한 파일만 완성본 폴더로 옮긴다. 기존 완성본이 있으면 먼저 백업한다.

## 새 사진에서 반드시 수정할 항목

- 작업 날짜와 원본·편집 결과·출력 폴더.
- 품번과 사진 수, 각 원본에 대응하는 편집 결과 파일.
- 원본 라벨의 자르기 영역과 실제 부착 표기의 복원 영역.
- 판매자 워터마크와 제거 대상 영역.
- 원본 해상도와 사진별 좌표. 다른 해상도에 예전 좌표를 그대로 사용하지 않는다.
- 제품 배치 공간과 워터마크 중심 위치.

복원 스크립트의 `GEN`, `FILES`, `PUMP_RECTS`, `DOOR_LABELS`, `DOOR_OVERLAYS`와 본문에 직접 적힌 복원 영역·위치는 10월 4일 사진 전용 값이다. 현재 스크립트에는 중간 실험 계산도 남아 있으므로 범용 실행 도구로 간주하지 않는다.

## 원본 표기 복원 시 주의사항

- 정렬은 SIFT 특징점과 변환 행렬을 이용한다. 코드의 최소 정렬 조건을 통과해도 시각 검수를 생략하지 않는다.
- 현재 최종 저장 경로는 편집 결과를 바탕으로 원본의 지정 표기 영역을 복원한다. 제품 전체가 원본 픽셀 그대로 보존된다고 가정하지 않는다.
- 워터펌프 일부 원본 표기는 판매자 색상 겹침을 줄이는 보정을 거친다. 보정 후 글자 모양과 숫자가 원본과 일치하는지 확인한다.
- 라벨 복원으로 글자가 맞더라도 주변 제품 구조가 바뀌면 그 결과를 채택하지 않는다.
- 같은 배치의 다른 원본에서 픽셀이나 템플릿을 가져오면 출처 사진과 사용 영역을 기록한다. 다른 각도의 제품 전체를 무단 대체하지 않는다.
- 가려진 핀, 구멍, 단자나 숨은 면을 생성하여 실제 제품의 증거로 제시하지 않는다.

## 배치와 저장 규격

- 최종 파일: 1000×1000 픽셀, PNG, 흰 배경.
- 대표사진: `<품번>.png`. 이후 사진: `<품번>_1.png`, `<품번>_2.png` 순서.
- 최종 저장 위치: `완성본/<품번>/`.
- 별도 라벨형 첫 장은 원본 라벨 세트를 상단 중앙에 두고 제품을 라벨 아래 남은 공간의 중앙에 놓는다. 기준 라벨 폭은 약 350픽셀, 위 여백은 약 20픽셀이며 세부 배치는 작업규칙.md를 따른다.
- 후속 장은 별도로 놓인 라벨을 제거한다. 제품 또는 제품 박스에 실제로 붙은 라벨은 유지한다.
- 제품과 박스를 함께 쓰는 사진은 별도 라벨을 제거하고 제품·박스를 한 세트로 중앙에 놓는다.
- 워터마크 문구는 KOREA AUTOPARTS, 승인 글꼴은 NotoSans-BoldItalic.ttf, 전체 가로 폭은 264픽셀이다. 스타일은 공통 마무리 도구의 값을 사용한다.

10월 4일 복원 스크립트의 출력은 `작업중/2026-10-04/<품번>/검수용/`이다. 스크립트가 저장했다는 이유만으로 완성본 또는 등록 가능한 사진으로 취급하지 않는다.

## 공통 마무리 도구의 조정 항목

- `--output-dir`: 저장 폴더.
- `--part-number`: 파일명에 사용할 품번.
- `--start-index`: 사진 번호 시작값. 기본값 0은 대표사진부터 저장한다.
- `--content-scale`, `--content-offset-x`, `--content-offset-y`: 제품 크기와 위치 조정.
- `--watermark-center-y`: 워터마크 세로 중심 위치.
- `--label-source`, `--label-crop`: 실제 원본 라벨 파일과 자르기 영역.
- `--label-width`, `--label-top`, `--label-clear-height`: 라벨 크기·위쪽 여백·기존 라벨 영역 정리.

공통 마무리 도구는 입력을 정사각형으로 맞출 때 일부를 잘라낼 수 있다. 제품이 잘리지 않도록 입력 단계에서 흰 여백을 넣어 정사각형으로 준비한다. 사진별 반복 옵션의 개수와 적용 순서도 입력 사진과 맞춘다.

## 최종 검수 및 업로드 기준

각 완성 파일을 원본과 나란히 놓고 1000×1000 크기로 한 장씩 확인한다.

- 품번과 사진 순서가 정확한가.
- 첫 장과 후속 장의 별도 라벨 처리 규칙을 지켰는가.
- 제품·박스·라벨·케이블 끝이 잘리지 않았는가.
- 핀 개수와 간격, 구멍·나사·각인·색상·질감이 바뀌지 않았는가.
- 라벨 글씨·숫자·바코드·로고가 원본과 일치하는가.
- 기존 워터마크 잔상, 뭉개짐, 반복 무늬, 합성 경계가 없는가.
- 흰 배경에 그림자·회색 얼룩이 남지 않았는가.
- 우리 워터마크의 폭·스타일·위치가 규칙과 맞는가.

불합격 파일은 검수용으로 남기고 완성본이나 eBay 등록에 사용하지 않는다. 업로드 후에는 API와 공개 갤러리에서 사진 내용·장수·순서를 다시 확인한다.

## 작업 기록에 남길 내용

작업 날짜, 참고 아이템 번호, 품번, 원본 파일명, 편집 결과 파일명, 사진별 수정 좌표, 다른 원본 사용 여부, 복원한 표기 영역, 최종 파일명과 장수, 검수 결과를 기록한다. 비밀값·토큰·API 키는 문서에 적지 않는다.

이 문서는 사용 규칙을 정리한 것이다. 새 사진에 대한 좌표 설정, 실제 편집 실행, 검수 완료를 대신하지 않는다.
