# 2026-10-04 사진 재작업 규칙

이 문서는 2026-10-04에 eBay 아이템 `324784237841` (`81230-1W030`)과 `324713554455` (`81230-3W000`)의 사진을 재작업하며 확정한 **한 장씩 편집·검수하는 방법**이다. 기본 시각 규격과 예외는 [`작업규칙.md`](../작업규칙.md), 사진 작업의 전체 기준은 [`PHOTO_WORK_RULES.md`](PHOTO_WORK_RULES.md)를 따른다. 내용이 다르면 최신 사용자 지시와 `작업규칙.md`가 우선한다.

## 시작 전

1. 새 아이템이나 새 품번마다 `AGENTS.md`, `작업규칙.md`, `docs/WORKFLOW.md`, `docs/PHOTO_WORK_RULES.md`를 다시 읽고 사진 유형·배치·제거 대상을 사용자에게 텍스트로 브리핑한다.
2. 아이템에 등록된 사진을 모두 수집해 수정하지 않은 원본을 보관한다. 각 장의 실제 제품·박스·라벨 여부를 확인하고, 제품이 없는 도해나 홍보 이미지만 편집 대상에서 제외한다. 품번은 원본 라벨에서 확인한다.
3. 이전 완성본이 있으면 새 결과로 교체하기 전에 별도 폴더에 백업한다. 원본과 실패 시안을 완성본으로 덮어쓰지 않는다.

## 한 원본에서 한 결과씩

1. 각 결과는 **해당 각도의 원본 한 장**에서 시작한다. 이미 편집한 다른 사진을 다음 사진의 원본으로 삼지 않는다. 다른 원본으로 대체하거나 실제 픽셀을 가져온 경우 결과 번호와 출처를 기록한다.
2. 기존 판매자 워터마크·별도 판매자 배너·불필요한 배경을 제거한다. 넓은 사각형 삭제나 인페인팅으로 글자 잔상, 뭉개짐, 반복 무늬, 잘린 테두리가 생기면 그 시안은 폐기하고 원본에서 다시 시도한다.
3. 제품의 외형, 카메라 각도, 금속 핀의 **개수·간격**, 구멍, 나사, 각인, 표면 질감과 박스의 실제 부착 라벨을 원본과 대조한다. 생성형 편집은 가려진 면의 실제 구조를 증명하지 않으며, 달라진 구조를 사실로 제시하지 않는다.
4. 이미지 편집 모델은 사용자 승인 범위에서만 사용한다. `AGENTS.md`의 추가 유료 API 호출 금지 설정을 임의로 해제하지 않는다. 모델이 만든 결과도 원본과 한 장씩 비교하고, 세부가 바뀌면 채택하지 않는다.

## 라벨·홀로그램·배치

- **첫 장의 별도 품번 라벨:** 원본의 글자, 숫자, 바코드, 로고와 작은 한글이 들어 있는 **실제 원본 픽셀**을 사용한다. 모델이 다시 그린 라벨로 대체하지 않는다. 라벨을 위쪽 가로 중앙에 약 350px 폭, 위 여백 약 20px로 배치하고, 제품을 그 아래 남은 공간의 중앙에 잘리지 않게 놓는다.
- **박스와 제품을 함께 쓰는 첫 장:** 별도 품번 라벨은 빼고 박스와 제품을 한 세트로 중앙에 둔다. 박스에 실제로 붙은 라벨은 원본 픽셀과 내용을 유지한다.
- **두 번째 장부터:** 별도로 놓인 품번 라벨·판매자 그래픽을 제거하고 제품만 둔다. 제품이나 박스에 실제로 붙은 표기는 유지한다.
- **홀로그램:** 유무·무늬·문자·상대 위치를 작업이나 검수의 조건으로 삼지 않는다. 내용을 추정하거나 재구성하지 않는다.
- **단자 확대 컷:** 원본이 이미 제품 일부만 보여주면 그 확대 사진의 의도를 유지한다. 보이지 않는 몸체를 새로 만들지 않는다. 합성 경계가 나타나면 핀과 커넥터를 자르지 않는 범위에서 프레임을 조정하고 다시 확인한다.

## 저장과 한 장씩 검수

1. 결과는 흰 배경의 **1000 × 1000 PNG**로 만든다. 원본 비율을 유지하고 필요한 만큼 흰 여백을 둔다. 제품·박스·라벨의 실제 끝은 자르지 않는다.
2. `assets/fonts/NotoSans-BoldItalic.ttf`를 사용하는 기존 마무리 도구로, 모든 장에 가로 폭 **264px**의 `KOREA AUTOPARTS` 워터마크를 같은 스타일로 넣는다. 단자·품번 등 중요한 정보가 가려지지 않도록 위치를 조정한다.
3. 저장 파일을 **각각 1000px 크기로 열어** 해당 원본과 비교한다. 첫 장 라벨의 원본 정보, 후속 장의 별도 라벨 제거, 판매자 워터마크 잔상, 제품의 핀·구멍·나사·각인·가장자리, 흰 배경, 새 워터마크를 검사한다. 축소 연락처 시트만으로 합격시키지 않는다.
4. 합격한 파일만 `완성본/<품번>/`에 `<품번>.png`, `<품번>_1.png` 순서로 저장한다. 기존 파일은 먼저 백업한다. 원본과 결과의 대응 관계 및 모델 편집 사용 여부를 작업 기록에 남긴다.
5. 완성 파일을 한 장씩 보여주고 **개별 다운로드 링크**를 제공한다. 사진 등록까지 요청받지 않았다면 사진 작업 결과와 등록 작업을 혼동하지 않는다.
