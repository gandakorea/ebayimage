# 이베이 상품 등록 규칙

## 사용자와 함께 등록하기

- 사용자는 등록할 때 세 가지를 알려준다: 참고 아이템 번호, 가격(USD), Shipping policy.
- 참고 상품은 전달받은 아이템 번호로 조회하고, 가격과 Shipping policy는 사용자가 지정한 값으로 설정한다.
- 참고 아이템 번호를 기준으로 새 상품 등록 초안을 작성한다.
- 사용자가 화면을 보며 알려주는 순서와 설정을 따른다. 필요한 항목은 하나씩 묻는다.

## 제목 기본 형식 — 2026-09-06 확정

`⭐Genuine 품번 부품명 For 차종 배기량 연식`

- 제목 맨 앞의 노란 별 `⭐`은 반드시 넣는다. 제목을 줄일 때도 제거하지 않는다.
- 각 단어의 첫 글자는 대문자, 나머지는 소문자로 쓴다.
- 사용자 지정 표기인 `2EA`, `LH`, `RH`는 대문자를 유지한다.
- 기본 예시처럼 별은 Genuine 앞에 하나만 두고, 품번은 하이픈 없이 Genuine 바로 뒤에 둔다.
- 공백과 기호를 포함해 80자 이내면 사용한다.

### 80자를 넘을 때

1. 제목에서 파츠넘버를 제외한다.
2. 그래도 80자를 넘으면 제목 끝의 시작·종료 연도를 각각 두 자리로 줄인다. 예: `2002-2006` → `02-06`.
- 좌우 한 쌍 판매 제목이 80자를 넘으면 `Left Right 2EA`를 `LH RH 2EA`로 줄여도 된다.
- 좌우 표기 축약을 품번·연식 축약 중 어느 단계에 적용할지는 아직 정하지 않았다. 위 방법 외의 추가 축약 기준도 미정이다.

### 수량 및 좌우 한 쌍 표기

- 2개 묶음 판매: 부품명 바로 뒤, `For` 앞에 `2EA`를 넣는다.
  - 예: `Belt Tensioner Pulley 2EA For Kia ...`
- 왼쪽·오른쪽 한 쌍 판매: 부품명 뒤, `For` 앞에 `Left Right 2EA`를 넣는다.
  - 예: `부품명 Left Right 2EA For 차종 ...`
  - 80자 초과 시 허용 표기: `부품명 LH RH 2EA For 차종 ...`

### 사용자 지정 기본 예시

`⭐Genuine 5721239000 Belt Tensioner Pulley For Kia Amanti Sedona 3.5L 2002-2006`

공백·기호 포함 78자이므로 품번과 네 자리 연식을 유지한다.

## 아이템 카테고리

- 사용자가 지정한 참고 이베이 상품의 아이템 카테고리(Item category)를 그대로 따른다.
- 스토어 카테고리(Store category)는 별도 항목이며, 위 규칙을 임의로 적용하지 않는다.
- 이번 참고 상품: `236877675342`, 품번 `57212-39000`.
- 이번 아이템 카테고리: `eBay Motors > Parts & Accessories > Car & Truck Parts & Accessories > Accessory Belts > Idlers & Tensioners`.

## 스토어 카테고리

- 제목에 나온 자동차 차종에 해당하는 스토어 카테고리를 선택한다.
- 제목의 차종이 하나뿐이면 스토어 카테고리도 하나만 설정한다.
- 제목의 차종이 두 개면 해당 차종의 스토어 카테고리를 두 개 설정한다.
- 이번 제목의 차종은 `Amanti`, `Sedona`이다.

## 아이템 상세 정보

- Brand는 항상 `Genuine Hyundai Mobis`로 입력한다.
- Country of Origin은 항상 `Korea, Republic of`(대한민국)로 설정한다. 상품 상세와 배송 영역의 원산지를 모두 확인한다.
- California Prop 65 Warning 항목은 입력하지 않는다. 참고 상품에서 복사된 내용이 있으면 비운다.

## 차량 호환 정보

- 차량 호환 정보(Compatibility)는 사용자가 지정한 참고 아이템을 기준으로 eBay 개발자 API를 이용해 가져와 적용한다.
- API에서 가져온 실제 호환 데이터를 사용하며, 제목만 보고 호환 차량을 임의로 추가하지 않는다.
- 적용 후 등록 초안에 호환 정보가 반영되었는지 확인한다.
- 사용자가 원하는 방식은 개발자 API로 호환표 전체를 일괄 처리하는 것이다. 이번 화면 수동 선택은 향후 기본 작업 방식으로 삼지 않는다.

## Description

- 본문 위의 Item condition은 항상 `New`로 선택한다.

- 항상 아이템 `336779935333`을 조회하고 `Item description from the seller` 아래 판매자 설명 전체를 복사한다.
- 서식을 유지해 등록 초안의 Description에 먼저 붙여넣고, 이후 사용자 안내에 따라 수정한다.
- 원본 설명에 포함된 다른 상품의 제목·품번·차종 문구는 수정 대상인지 확인한다.
- 본문에 있는 기존 상품 제목을 지우고, 제목 규칙에 맞게 작성한 현재 상품의 Item title을 복사해 그 자리에 넣는다.
- 설명의 원본 글꼴·크기·색상·표·그림을 유지하고, 교체 후 실제 표시와 이미지 로딩을 확인한다.

## 가격 및 재고 수량

- 가격은 사용자가 참고 아이템 번호와 함께 알려주는 금액(USD)을 입력한다.
- 등록 재고 수량(Quantity)은 항상 `5`로 설정한다. 제목의 묶음 판매 수량 표기와는 별개이다.
- 이번 상품: 참고 아이템 `236877675342`, 품번 `57212-39000`, 가격 `US $93.68`, Quantity `5`.

## Shipping policy

- 사용자는 `normal` 또는 `fast` 중 하나를 지정한다.
- `normal` → `7day normal`, `fast` → `7day fast`를 선택한다.
- 이번 상품 `57212-39000`은 `7day normal`을 사용한다.

## 이번 등록 완료 기록 — 2026-09-06

- 참고 아이템 `236877675342`의 호환 정보 29개를 API로 조회하고, 이번에는 화면에서 선택해 초안에 저장했다.
- 제목과 본문 제목을 위의 78자 기본 예시로 맞췄고, 본문 원본의 서식과 VIN 안내 그림을 복원했다.
- 상품 상태 `New`, 가격 `$93.68`, 재고 `5`, 배송 정책 `7day normal`을 적용했다.
- 이번 세션에서 최종 `List it` 클릭은 자동 승인 검토에 의해 사용자 직접 실행으로 제한되었다. 이를 API로 우회하지 않는다.
- 사용자가 직접 `List it`을 누른 뒤 등록 완료를 알려주었다. 새 판매 아이템 번호는 아직 확인하지 않았다.
