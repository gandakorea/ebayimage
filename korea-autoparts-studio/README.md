# Korea Autoparts Image Studio

자동차 부품 사진을 분석해 1000 x 1000 PNG 대표이미지로 만드는 로컬 웹 앱입니다.

## 실행

현재 사용자 설정(2026-09-05)은 음성 및 추가 유료 API 호출 중단입니다. 이전·설치 확인에는 API 키를 입력하거나 연결 시험을 실행하지 않습니다. 아래 API 설정은 사용자가 다시 활성화한 경우에만 적용합니다.

```powershell
Copy-Item .env.example .env.local
npm ci
npm run dev
```

`.env.local`의 `OPENAI_API_KEY`에 서버용 API 키를 설정합니다. 키는 브라우저로 전달되지 않습니다.

```text
OPENAI_API_KEY=...
OPENAI_VISION_MODEL=gpt-5.4-mini
OPENAI_IMAGE_MODEL=gpt-image-2
OPENAI_IMAGE_QUALITY=high
```

## 처리 흐름

1. 사진에서 제품, 박스, 독립 라벨과 홀로그램, 기존 워터마크를 분석합니다.
2. 라벨의 파츠넘버를 읽어 `XXXXX-XXXXX.png` 형식의 파일명을 만듭니다.
3. 원본 전체를 워터마크 중심으로 한 번 더 검사해 모든 탐지 영역을 합칩니다.
4. 마스크를 안내로 사용한 OpenAI 고품질 편집본 전체를 사용해 사각형 조각과 이음선을 방지합니다.
5. 편집 뒤에는 용량을 줄인 검사용 사본으로 잔여 워터마크를 검사하고, 남아 있으면 한 번 더 편집합니다. 재검사만 실패하면 편집 결과를 버리지 않고 `확인 필요`로 남깁니다.
6. 독립 라벨과 홀로그램을 원본에서 각각 보존하고 제품 영역에서는 제외합니다.
7. 흰 배경에 라벨형, 박스형, 제품형 규칙으로 배치하고 `KOREA AUTOPARTS` 워터마크를 넣습니다.
7. 불확실한 결과는 `확인 필요`로 분리합니다. 사용자가 미리보기에서 승인한 사진만 일괄 저장됩니다.

사진 분석과 편집을 실행하면 업로드한 사진이 설정된 OpenAI API로 전송됩니다. 이미지 편집은 기본적으로 `gpt-image-2`의 high 품질을 사용합니다. 잔여 워터마크가 발견될 때만 두 번째 편집을 실행하므로 해당 사진은 API 비용이 추가될 수 있습니다. API 키가 없을 때는 로컬 합성만 수행하며 결과를 반드시 `확인 필요`로 표시합니다.
